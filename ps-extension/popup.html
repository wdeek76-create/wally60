PROPSHOP CSV AUTO-FORMAT · NBA + NFL

Download a projections CSV as usual — NBA (Tabs, Sharpr, STOK, RG, Saber, RotoWire, Dimers) or NFL (Dimers, FTN, RotoWire, FantasyPts, 4for4, RTS, Stok) — and it is replaced by the PropShop version, named like RG-NBA 2.17pm.csv / STOK-NFL 2.17pm.csv. NFL sources that come in parts (Stok pass / rush / rec, RotoWire QB / RB-WR-TE, FTN) are merged per player across the day, so the newest file always carries everything. Other CSVs are left alone.
