# FD Enter to Bet (Brave / Chrome, desktop)

Press **Enter** on FanDuel's bet slip and it clicks **Place bet** for you, the same button you'd click.
It never changes your stake or picks a bet.

## Install (Brave)
1. Download this `fd-enter-extension` folder to your PC.
2. Go to `brave://extensions`.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and pick the `fd-enter-extension` folder.
5. Open FanDuel. A small "⏎ Enter bets: ON" tag shows bottom-left.

## Use
- Add the bet, type your stake, press **Enter**. It presses Place bet.
- **Alt+E** turns it on / off (remembered).
- At most one press every 2 seconds (no double bets from a held key).

If FanDuel renames the button and Enter stops working, tell Claude what the button says.
